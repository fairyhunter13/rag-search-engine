# Policy

* [Evidence from a private corpus travels as a measurement, never as an
  identifier](private-evidence-is-a-measurement-not-an-identifier.md) - This repository is public
  and it is fed by private corpora. A count carries the finding and names nothing. The ban list in
  `tests/test_public_hygiene.py` holds only the terms somebody thought to add, so the reviewer is
  the gate.
