# coderag

A code-RAG engine for agents. Two MCP tools: index a root and its federated projects, search them.

**Being rebuilt from zero.** The previous engine — 11,843 lines across five subsystems — was
deleted in `365a235`. Its incident record is in [docs/archive/](docs/archive/), unindexed and
unmaintained, kept because the measurements in it are the repo's most expensive asset.

Nothing here is installable yet. This file is rewritten from the shipped surface once the engine
runs end to end.
